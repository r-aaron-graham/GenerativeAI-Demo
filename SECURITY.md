# Security reporting and scope

Report vulnerabilities through GitHub Security advisories when available. If private reporting is unavailable, open an issue requesting a private channel and omit exploit details, credentials, and sensitive documents.

Treat source documents and model output as untrusted input. This example evaluates dictionaries and bundled fictional text locally. The controlled grammar covers a small set of policy statements. Deployment owners must assess input size limits, authenticated access, request timeouts, audit retention, and source provenance for their environment.

Container verification uses an unprivileged user, a read-only filesystem, and disabled network access. Review and update the base image regularly. Synthetic fixture results provide limited evidence for decisions involving unseen documents.
